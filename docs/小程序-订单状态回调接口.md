## 小程序对接接口文档：订单状态回调更新

### 背景
小程序在用户完成**支付**或发生**退货/退单**后，需要回调本服务更新订单状态。  
本接口会更新**海典同步库**（`haidian.datasource`）中的**表B** `mcp_order_create_order_log`：  
- `order_status` / `status_update_time`  
- 小程序回调数据 `mini_callback_data`（包含发票信息与业务扩展字段）

---

### 状态码对照（必读）
- **1**：预下单（用户调用 `core_order_create` 后默认写入）
- **2**：已领单
- **3**：配送中
- **4**：待上传凭证（预留）
- **5**：完成
- **6**：驳回（预留）
- **7**：已退单

---

### 接口 1：更新订单状态

- **HTTP Method**：POST  
- **URL**：`/mcp/core_order_status_update`  
- **Content-Type**：`application/json`

#### 请求参数（Body JSON）
- **orderId**（string，选填）：对外订单标识（推荐传）。通常取 `core_order_create` 返回的 `data.orderId`
- **pendingId**（string，选填）：本服务生成的 `pendingId`（兜底定位）
- **statusCode**（int，推荐）：订单状态码，仅允许 `1~7`
- **status**（string，兼容）：订单状态中文，支持 `预下单/已领单/配送中/待上传凭证/完成/驳回/已退单`
- **invoiceInfo**（string，选填）：发票信息/抬头等（建议传 JSON 字符串）。若为空则不覆盖已保存内容。
- **callbackData**（string，选填）：小程序业务扩展回调数据（建议传 JSON 字符串，如支付流水、支付时间、渠道等）
- **receiverName**（string，选填）：领单人名称
- **completionImagesJson**（string，选填）：完成图片内容（JSON 字符串）

#### 参数约束
- `orderId` 或 `pendingId` **至少传一个**
- `statusCode` 与 `status` **至少传一个**（推荐只传 `statusCode`）

---

### 请求示例

#### 1）订单完成回调（示例）
```json
{
  "orderId": "PD-2026-03-17-58179780",
  "statusCode": 5,
  "receiverName": "张三",
  "completionImagesJson": "{\"images\":[\"https://xx/a.jpg\",\"https://xx/b.jpg\"]}",
  "invoiceInfo": "{\"title\":\"四川某某公司\",\"taxNo\":\"9151xxxx\",\"email\":\"xx@xx.com\",\"needInvoice\":true}",
  "callbackData": "{\"payChannel\":\"wx\",\"transactionId\":\"420000xxxx\",\"payTime\":\"2026-03-19 10:11:12\"}"
}
```

#### 2）退单完成 → 已退单
```json
{
  "orderId": "PD-2026-03-17-58179780",
  "statusCode": 3
}
```

#### 3）仅有 pendingId 的兜底场景
```json
{
  "pendingId": "PD-2026-03-17-58179780",
  "statusCode": 2
}
```

---

### 响应格式
统一结构：
- **code**：`0` 成功；`400` 参数错误；`500` 服务错误
- **msg**：说明
- **data**：结果对象

#### 响应示例：更新成功
```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "updated": 1,
    "orderId": "PD-2026-03-17-58179780",
    "pendingId": null,
    "statusCode": 5,
    "invoiceInfoSaved": true,
    "callbackDataSaved": true,
    "receiverNameSaved": true,
    "completionImagesSaved": true
  }
}
```

#### 响应示例：未找到记录
```json
{
  "code": 0,
  "msg": "未找到对应订单记录",
  "data": {
    "updated": 0,
    "orderId": "PD-xxx",
    "pendingId": null,
    "statusCode": 2
  }
}
```

#### 响应示例：参数错误
```json
{
  "code": 400,
  "msg": "orderId 或 pendingId 至少传一个",
  "data": null
}
```

---

### 对接建议（小程序侧）
- **下单后（MCP 创建记录）**：状态默认 `1=预下单`（无需回调）
- **小程序常用回调状态**：`2=已领单`、`3=配送中`、`5=完成`、`7=已退单`
- **预留状态**：`4=待上传凭证`、`6=驳回`
- **建议传参**：优先传 `orderId`（即 MCP 下单返回的 `data.orderId`）
