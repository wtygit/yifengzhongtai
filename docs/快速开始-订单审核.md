# 快速开始 - MCP订单审核

## 一、解决SQL语法错误

### ❌ 错误信息
```
1064 - You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near '(
    r.user_request_data,
    '$.items[*]' COLUMNS (
        drug_name VARCH' at line 39
```

### ✅ 解决方案

**你的MySQL版本是5.7，必须使用MySQL 5.7版本的SQL！**

#### 步骤1：确认MySQL版本
在积木报表SQL编辑器中执行：
```sql
SELECT VERSION();
```

#### 步骤2：选择正确的SQL文件

**如果显示 5.7.x**：
- 使用：`db/jimureport_mcp_order_request_view_mysql57.sql`（推荐）
- 或使用：`db/jimureport_mcp_order_request_view_simple.sql`（最简单）

**如果显示 8.0.x**：
- 使用：`db/jimureport_mcp_order_request_view.sql`

#### 步骤3：在积木报表中使用

1. 进入积木报表工作台
2. 点击「新建报表」
3. 选择「SQL数据集」
4. **重要**：选择**海典同步库数据源**（不是jimureport主库）
5. 复制对应的SQL文件内容
6. 粘贴到SQL编辑器
7. 执行

## 二、访问前端审核页面

### 方式1：直接访问URL
```
http://your-server:port/mcp/order-audit
```

### 方式2：从导航菜单访问
1. 访问任意管理页面（如 `/api-generator/list`）
2. 点击顶部导航栏的「MCP订单审核」链接

### 页面功能
- ✅ 查看订单列表（可按状态筛选）
- ✅ 查看患者信息和药品列表
- ✅ 审核通过/驳回操作
- ✅ 自动刷新

## 三、使用积木报表查看数据

### 配置步骤

1. **配置数据源**（如果还没有）
   - 进入积木报表管理后台
   - 数据源管理 → 添加数据源
   - 配置信息与 `application.yml` 中的 `haidian.datasource` 一致

2. **创建报表**
   - 进入报表工作台
   - 新建报表 → SQL数据集
   - **选择海典同步库数据源**（重要！）

3. **输入SQL**
   - 根据MySQL版本选择对应的SQL文件
   - 复制SQL内容
   - 粘贴到SQL编辑器

4. **设计报表**
   - 按 `pending_id` 分组
   - 主表显示订单基本信息
   - 明细表显示药品列表

## 四、常见问题排查

### Q1: 前端页面显示"加载失败"

**检查项**：
1. 后端服务是否启动
2. 访问 `http://your-server:port/mcp/order-audit-list` 是否能返回数据
3. 浏览器控制台是否有错误信息

**解决方法**：
- 检查后端日志
- 确认接口路径正确
- 检查跨域配置（如果前端和后端不在同一域名）

### Q2: SQL执行报错

**检查项**：
1. MySQL版本是否正确（执行 `SELECT VERSION();`）
2. 是否使用了对应版本的SQL文件
3. 表是否存在（执行 `SELECT COUNT(*) FROM mcp_order_create_request_log;`）
4. 数据源是否正确（必须是海典同步库）

**解决方法**：
- 使用最简单的SQL：`jimureport_mcp_order_request_view_simple.sql`
- 检查表结构：`DESC mcp_order_create_request_log;`

### Q3: 查询不到数据

**检查项**：
1. 表中是否有数据：`SELECT COUNT(*) FROM mcp_order_create_request_log;`
2. 数据源是否正确（海典同步库，不是jimureport主库）
3. 审核状态筛选是否正确

**解决方法**：
- 先调用 `core_order_create` 接口创建测试数据
- 确认数据源配置

### Q4: 前端没有菜单

**解决方法**：
- 直接访问：`/mcp/order-audit`
- 或从其他页面（如 `/api-generator/list`）的导航栏点击「MCP订单审核」

## 六、测试流程

1. **创建测试订单**
   ```bash
   POST /mcp/core_order_create
   {
     "patientName": "测试用户",
     "patientPhone": "13800138000",
     "items": [
       {"drugName": "测试药品", "qty": 1}
     ]
   }
   ```

2. **查看订单**
   - 前端页面：访问 `/mcp/order-audit`
   - 积木报表：使用SQL查询

3. **审核订单**
   - 前端页面：点击「审核」按钮
   - API接口：`POST /mcp/core_order_approve`

4. **查看结果**
   - 前端页面自动刷新
   - 积木报表中查看审核状态
