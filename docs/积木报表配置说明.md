# 积木报表配置说明 - MCP订单审核

## 一、数据源配置

### 重要提示
**积木报表必须配置海典同步库数据源**，因为 `mcp_order_create_request_log` 表存储在海典同步库中，不是本系统数据库（jimureport）。

### 配置步骤

1. 登录积木报表管理后台
2. 进入「数据源管理」
3. 添加数据源，配置信息与 `application.yml` 中的 `haidian.datasource` 一致：
   ```yaml
   haidian:
     datasource:
       url: jdbc:mysql://your-haidian-host:3306/your-database
       username: your-username
       password: your-password
   ```
4. 测试连接，确保可以连接成功

## 二、创建报表

### 1. 新建报表

1. 进入积木报表工作台
2. 选择「数据报表」文件夹
3. 点击「新建报表」
4. 选择「SQL数据集」

### 2. 选择数据源

**重要**：选择刚才配置的**海典同步库数据源**，不要选择默认的jimureport数据源。

### 3. 输入SQL查询

根据你的MySQL版本选择对应的SQL文件：

#### MySQL 8.0+ 版本
使用：`db/jimureport_mcp_order_request_view.sql`

#### MySQL 5.7 版本
使用：`db/jimureport_mcp_order_request_view_mysql57.sql`

**注意**：如果执行SQL时报错 `JSON_TABLE` 语法错误，说明你的MySQL版本是5.7，请使用MySQL 5.7版本的SQL文件。

### 4. 设计报表

#### 建议的报表布局

**主表（订单基本信息）**：
- pending_id（待下单单号）
- patient_name（患者姓名）
- patient_phone（患者手机号）
- patient_id_card（患者身份证）
- audit_status_text（审核状态）
- create_time（创建时间）
- audit_time（审核时间）
- audit_remark（审核备注）

**明细表（药品列表）**：
- drug_name（药品名称）
- spec（规格）
- qty（数量）
- ware_id（商品ID）
- bar_code（条码）

**筛选条件**：
- 审核状态（audit_status）：0待审核、1已通过、2已驳回
- 创建时间范围

#### 报表设计技巧

1. **分组显示**：按 `pending_id` 分组，一个订单显示一行基本信息
2. **明细展开**：药品列表作为明细表，一个订单可能有多行药品
3. **条件筛选**：添加筛选条件，方便查看待审核订单（`audit_status = 0`）

## 三、常见问题

### Q1: 执行SQL报错 "JSON_TABLE" 语法错误

**原因**：MySQL版本是5.7，不支持 `JSON_TABLE`（需要MySQL 8.0+）

**解决**：使用 `db/jimureport_mcp_order_request_view_mysql57.sql` 文件中的SQL

### Q2: 查询不到数据

**检查项**：
1. 数据源是否配置为海典同步库（不是jimureport主库）
2. 表名是否正确：`mcp_order_create_request_log`
3. 表中是否有数据（可通过 `SELECT COUNT(*) FROM mcp_order_create_request_log` 检查）

### Q3: items数组没有展开

**原因**：可能是JSON格式问题或items为空

**检查**：
```sql
-- 检查JSON格式
SELECT pending_id, user_request_data FROM mcp_order_create_request_log LIMIT 1;

-- 检查items是否存在
SELECT pending_id, JSON_EXTRACT(user_request_data, '$.items') FROM mcp_order_create_request_log LIMIT 1;
```

### Q4: 一个订单显示多行

**说明**：这是正常的。如果一个订单有多个药品（items数组有多个元素），每个药品会显示一行。这是为了在报表中清晰展示所有药品信息。

如果需要只显示一行订单信息，可以在报表设计时：
- 使用分组功能，按 `pending_id` 分组
- 主表显示订单基本信息
- 明细表显示药品列表

## 四、数据源确认

### 如何确认数据源是否正确

在积木报表的SQL编辑器中执行：

```sql
-- 应该能查询到数据
SELECT COUNT(*) FROM mcp_order_create_request_log;

-- 如果报错"表不存在"，说明数据源配置错误
```

### 数据源配置位置

- **积木报表配置**：管理后台 → 数据源管理
- **应用配置**：`application.yml` → `haidian.datasource`

两者必须指向同一个数据库。
